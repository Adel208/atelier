# Atelier — page d’accueil

Page d’accueil d’une maison de coiffure premium mixte, construite avec l’App Router de Next.js, React, TypeScript, Tailwind CSS et GSAP / ScrollTrigger.

## Lancer en local

Prérequis : Node.js 22.13 ou plus récent.

```bash
npm ci
npm run dev
```

Ouvrir l’adresse locale affichée par le serveur. Le hero utilise deux lames SVG sculpturales : leur position, leur ouverture et les reflets bronze suivent le scroll dans les deux sens. Le hero se termine sur Personnalité ; le manifeste ivoire entre naturellement depuis le bas avec ses révélations typographiques.

## Notes

- Le hero passe à une composition fixe si `prefers-reduced-motion` est activé.
- Les portraits éditoriaux sont des visuels de démonstration générés pour cette maquette.
- L’adresse, le téléphone, l’e-mail, l’Instagram et les horaires sont temporaires et à remplacer avant mise en ligne publique.
- Le projet utilise l’adaptateur Vinext fourni par Sites pour compiler l’App Router sur son runtime d’hébergement.
